AR VEICHI Inverter + Washing Machine

index.html = AR demo
hiro-marker-print.png = printable marker sheet

IMPORTANT: index.html uses AR.js preset="hiro". The included PNG is a print-friendly visual marker, but for reliable tracking use the standard AR.js Hiro marker if the included visual does not track on your device.

Run:
1) Put all files in the same folder.
2) Start a local server: python -m http.server 8000
3) Open http://localhost:8000/ on a browser.
4) Allow camera access and point at the Hiro marker.
5) Use +100/-100/STOP. Speed is simulated from 0-1500 RPM.

For a real VEICHI model, replace the primitive inverter with a .glb/.gltf model.
